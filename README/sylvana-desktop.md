# Sylvana for Windows

Choose **Continue with Sylvana**. The [hosted dashboard](https://sylvana-legal-web-app.vercel.app) handles account creation, email confirmation, recovery, firm onboarding and desktop approval. The one-time return code is bound to the app's proof. Existing local ownership must match the verified web identity; accounts are never merged by email.

The installed 0.46.3 development application uses real Standard/Max services. The dashboard controls members, paid seats, weekly allowances, resets, devices and permitted AI services. Legal Compliance requires managed zero-data-retention routing. When disabled, firm-authorized ChatGPT OAuth and API connections remain available. Platform administrator LLM use is exempt from allowance debits while upstream costs remain recorded.

Chats, documents, drafts, native history and direct-provider credentials stay on the computer. Cloud records contain identity, memberships, device authorization, budgets and numeric accounting. Relay content is processed in memory; upstream credentials remain on the VPS. Temporary service failures retain credentials for retry.

The Windows profile selector is %USERPROFILE%\.sylvana\desktop\profile-location.json. Recovery requires the profile, encryption keys, database and managed files together. Normal shutdown and a verified backup precede local upgrades.

The [public download](https://sylvana-legal-web-app.vercel.app/api/download) remains 0.46.1. Its qualified archive lacks the current desktop policy header and cannot satisfy current server account verification. A compatible qualified installer is required before new-client rollout. [Current verification and operating limits](../docs/desktop/provider-platform-hardening.md) distinguish installed acceptance from public-release qualification.
