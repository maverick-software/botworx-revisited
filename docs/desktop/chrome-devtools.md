# Google Chrome tools

October 16, 2026 · Installed private release 0.31.1

Agentopia bundles Google's unmodified Chrome DevTools MCP server 1.11.0 and its notices. Its 370 package files are pinned by SHA-256, and the original npm archive was checked against its pinned SHA-512 integrity value. The server runs with Electron's Node runtime; the installed application does not require a separate Node.js installation or an `npx` download. Usage statistics, performance-trace URL submission to CrUX, and update checks are disabled.

Open Plugins → Chrome DevTools, enable the plugin for your account, and assign it to the agents that should use it. Choose a connection:

- **My current Chrome session:** open Chrome connection settings, enable Remote debugging at `chrome://inspect/#remote-debugging`, connect in Agentopia, and approve Chrome's own permission prompt. Chrome 144 or later is required. This shares that Chrome profile's tabs and signed-in site state. Disconnecting Agentopia leaves the existing Chrome browser running.
- **Separate Agentopia Chrome profile:** Agentopia starts the installed Chrome executable with a dedicated profile for the signed-in Agentopia account. Its cookies and sign-ins persist separately from regular Chrome. Disconnecting closes the Chrome process launched for this profile.

A connection is deliberately explicit for each app session. It is not silently restored after restarting Agentopia. Signing out, changing accounts, disabling the plugin, or closing Agentopia disconnects the managed runtime. An interrupted connection can be cancelled before it launches Chrome, and concurrent connection attempts for the same account are rejected.

In a chat, open Add → Tools & plugins and select Chrome DevTools. The existing Codex harness discovers and calls the 33 schema-checked tools through Agentopia's private host MCP connection. The provider can be changed between ChatGPT and OpenRouter while retaining the same Chrome session. Each Chrome operation requires review of its tool name and arguments, including when Full access is selected. Agent ownership, plugin grants, connection identity and tool schemas are checked again after approval and before queued execution. Plan mode exposes a fixed set of reading tools and withholds file output and mutating operations.

The tool set includes page navigation, accessibility snapshots, screenshots, keyboard/mouse input, JavaScript evaluation, uploads, console/network inspection, performance traces, and supported debugging tools. Page IDs route operations to a specific tab; calls are serialized within the account's Chrome connection. Browser input receipts are unique per request, native child, and provider call ID, so a repeated delivery cannot click or submit twice.

Screenshots are preserved as image content in the MCP result and displayed as previews in chat activity. Their base64 data is omitted from the text summary sent alongside the image. PNG, JPEG and WebP images have bounded sizes; malformed content is rejected. The native harness receives actual image blocks, and each provider's live vision behavior must be checked with real inference before release.

Local file inputs must be attached to the current chat. Workspace ownership, protected paths, hidden/credential exclusions and link checks apply. Inputs are hashed before approval and checked again before use. Uploads use private copies, allowing Chrome to read them after the selection operation returns. These copies are limited to 20 MB each, 40 MB per operation and 100 MB per connected session; they are removed on disconnect or on the next connection after an interrupted app exit. Attached UTF-8 JavaScript sources are checked and supplied inline for browser evaluation. Chrome cannot navigate `file:`, `chrome:`, extension or DevTools pages through this plugin.

Output filenames are resolved inside the conversation's Chrome artifacts folder under the account's Agentopia application data. Parent traversal and paths outside that folder are rejected. Backups include saved Chrome artifacts. Dedicated Chrome sign-ins and temporary upload copies are excluded from backups. The dedicated Chrome profile is mutable account data and is never included in the application installer.
