# New chats start with a closed workspace — installed75 interface repair

The October23 user screenshot showed a blank chat beside a previously opened document. Every unsent chat used the same saved workspace scope, `home`. New chat reset the conversation but reloaded that scope, so its document/browser tabs reappeared.

New chat now flushes pending file edits and the current conversation layout, then resets the home workspace to empty and closed. It retains pane sizing. Existing conversations keep their own saved tabs. Startup on an unsent chat also ignores old home tabs, so it does not read the previous document or reopen its browser. Explicitly opening a workspace folder/browser is still available. Deferred workspace actions from an earlier navigation are invalidated when a new chat starts.
