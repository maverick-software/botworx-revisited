# Sign-in copy and composer appearance repair

October 18, 2026. This repair removes the two sign-in captions marked in the user's screenshots: “Powered by PostgreSQL and Supabase” and “Account sign-in works locally. Connect an AI provider after signing in.” The active-agent selector now sets its own theme foreground, stays readable while disabled during work and starts at the same input edge as other context. The `Message [agent]` placeholder uses 14 px text at 55% opacity. Typed messages retain 15 px text; the large-text preference uses a 16 px placeholder and 17 px input.

The changes exist in the current source and in a separate frontend built from the frozen **0.44.17** source. The maintenance source changes `Panels.tsx`, `agent-style.css`, `style.css` and `Attachments.tsx`. The new frontend has been applied to the ordinary physical installation as a reversible **UI-only repair**. Its executable, backend archive, database software, migrations and schema remain unchanged. The installed version still reports 0.44.17/schema59. Future installers must include these source changes; the earlier frozen 0.44.18 and 0.44.19 images predate this repair.

The exact prepared frontend passed its TypeScript check and rendered in an isolated Electron application with a controlled local bridge. The checks exercised sign-in in both themes, active-agent menu operation, contrast above 4.5:1 for enabled and working-state labels, placeholder versus typed-text styling, narrow toolbar layout and the large-text preference. This process contacted no production backend or AI service. The generated screenshots provide a visual review of the actual built assets.

Applying the repair first required Agentopia to be closed. Its existing draft-save check reported an error. The physical ordinary and package-cache credential/state files and attachments were copied and hash-checked before confirming closure. This work did not establish the cause of that save error. Additional closed-profile snapshots were captured during the UI replacement; their hashes remained unchanged throughout the replacement. The original UI directory was retained beside the replacement for recovery, and another copy remains in the repair evidence folder. No account password was changed.

Private build, visual-check and application receipts are under `.supabase/desktop-composer-appearance/repair-1792357610611/`: `prepared.json`, `verification.json`, `live-state-preserved.json`, `applied.json` and the screenshots. `applied.json` retains all original and replacement UI file hashes and the unchanged backend archive hash. The guarded application script refuses a running Agentopia process, an unexpected backend archive or an installed UI differing from the original recorded 0.44.17 resources or an explicitly verified preceding UI repair.

The saved-state snapshots are limited to credentials, Local State, preferences, runtime/window metadata and attachments. They do not replace a complete physical-profile and database backup before a larger release. The earlier source scheduling/artifact work remains uninstalled, and the broader desktop acceptance goal remains active.
