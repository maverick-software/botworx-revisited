# Continuous chat history and conversation timeline

Earlier messages remain in the normal conversation scroll area. The previous-message disclosure and its horizontal separator have been removed. A quiet row of marks at the left edge provides navigation between user prompts, highlights the current reading position, and identifies exchanges with pending decisions. Each mark has a prompt preview and a keyboard-accessible button. Long conversations use up to 64 overview marks while retaining every message in the transcript.

Choosing a mark disables following the latest response before moving the reading position. Appending or streaming a reply therefore leaves a reader of earlier messages in place. The existing return-to-latest control resumes following. Saved source citations and pending tool decisions remain available in the continuous history. Individual long prompts, activity details, and subagent details retain their own disclosures.
