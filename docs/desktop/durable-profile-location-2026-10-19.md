October 19, 2026. This is qualified source support, not an installed migration. Ordinary Agentopia0.44.41 remains open on its existing physical profile. No ordinary account, credential, database, runtime registration or provider setting is changed by this work.

## Source behavior

Packaged standard per-user installations can select a completed migration at the current Windows home's `.agentopia/desktop/profile`. Selection happens before Electron initializes its session or encrypted storage. A private `profile-location.json` binds the directory to the exact installation root and private runtime instance. It contains a hash of the immutable migration receipt; the receipt must attest a complete byte-verified copy, successful encrypted-storage validation and native-history validation.

The source keeps the existing profile whenever there is no migration record. A present but incomplete, altered, mismatched, linked or aliased migration fails before session initialization. It does not silently choose another credential store. Retained Store-cache installations, unrelated executables, development builds and explicit isolated test profiles retain their prior behavior. The new private directory and its retained contents are excluded from chat file attachment, alongside both old AppData layouts.

The selector does not copy or activate the ordinary profile on its own. Production delivery still needs a stopped-profile migration controller, validation and publication of the location record, and a qualified new application package. In particular, activation must follow encrypted-copy validation; writing a record while a copy is still being prepared is not a supported migration procedure.
