## What changed

Moving the private profile can also change the default public export directory. Previously the saved original link could create a fresh copy there and overlook the edited copy registered under the former directory. Resolution now checks the current account's registered copies in sibling application export roots, using the same chat/source/version identity. It reuses the edited copy and its reference, including when an earlier version already created an unedited replacement.

Only matching owned registrations participate. Removed references, other owners, unrelated paths, linked files and account changes cannot grant access. If two copies contain different edits, both remain intact and the user is asked to choose a copy in the workspace. This acceptance covers recalculated export roots in the same home directory. Different-home restoration, missing original sources and full public-output recovery remain separate requirements.
