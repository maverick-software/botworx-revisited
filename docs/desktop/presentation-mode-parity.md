October 19, 2026. **Presentation mode is implemented and qualified in source, and is not installed.** The ordinary app remains on [0.44.47 office-preview-3](office-preview-installed-0.44.47.md), with its working formatted spreadsheet and slide previews.

The actual reference was exercised with the sample PowerPoint: Present opens full screen, fits the slide to the screen while preserving its proportions, and offers floating previous/next, page count and exit controls. The controls hide while idle. Arrow keys navigate slides; Escape returns to the preview at the selected slide. The reference was returned to its original PDF afterward.

Agentopia now implements that behavior. It keeps the existing isolated document frame mounted, preserves the selected slide, and restores preview zoom and keyboard focus on exit. Fit also centers the ordinary preview within the pane. The slide is constrained by both screen width and height, so standard and wide slides remain fully visible. Tab reaches and cycles the floating controls. Replacing or closing a presenting document exits full screen and resets its state.

Full screen is requested by the trusted application main frame. The new permission predicate accepts only user-activated `fullscreen` for the owned `agentopia://app` main frame. Document/browser subframes, other origins, embedded credentials/ports and `automatic-fullscreen` remain denied. The document iframe retains its opaque sandbox, no application bridge, blocked external resources and no fullscreen permission. The implementation follows Electron's [documented full-screen permission handling](https://www.electronjs.org/docs/latest/api/session).

An actual denied request exposed an Electron behavior: the promise can remain pending after its permission callback refuses the request. The UI now stops waiting after two seconds, explains the failure and permits retry. Duplicate requests are disabled while pending; timers and state are cleared when a file changes or closes.
