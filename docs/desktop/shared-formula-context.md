The implementation follows the master/follower relationship described by [Microsoft's CellFormula format reference](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.cellformula?view=openxml-3.0.1). It adjusts relative A1 references while keeping absolute references, quoted strings, sheet qualifiers, structured references and named ranges intact. Whole-row/column references, unions/intersections, quoted/external sheet qualifiers and worksheet bounds have specific checks. Expressions are never evaluated and external references are never fetched. Missing or ambiguous masters and unsupported/malformed expressions are identified as unavailable in extracted text, preserving any saved result. Expansion is bounded per formula and cumulatively for each worksheet.
