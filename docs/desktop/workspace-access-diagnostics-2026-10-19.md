Source now offers `diagnose_workspace_access` after a failed write. It accepts only an already selected, owned folder reference and an empty relative path. It reads at most 256 recent Defender block events, matching the exact installed PowerShell, Python or Node program and selected folder boundary. Results expose only bounded program basenames and UTC timestamps. Private relative paths are excluded. The folder identity and account/policy authorization are checked again after the read. The fixed query receives JSON through stdin, verifies its pinned PowerShell binary, times out, and never changes files, permissions or protection settings. No matching event does not prove write access.
