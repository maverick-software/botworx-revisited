# Plugin ownership and credential qualification

The runtime now assigns the existing browser, files/terminal, computer, workspace-agent, document/planning, automation, and retained Composio API executors to pinned bundled plugins. The broker filters model tool advertisements and the executor checks access again before execution and after reviews. Native command/file approvals, patch execution, and child-agent availability follow these grants. Existing agents retain their effective host access through migration receipts; later deselection survives repeated seeding. New creation catalogs save the default enabled host selection once and preserve an existing empty selection.

Credentials are projected as public metadata from the existing Vault and Windows protected store. Account search keys override shared administrator keys; removing an account key saves an explicit disconnected state. The page distinguishes stored-credential checks from provider checks and obtains actual MCP tool schemas only through the existing guarded inspection operation. Replacement and removal keep the existing type-specific handlers. Removed Stripe, provider-catalog, and prompt-library desktop handlers no longer write retained historical records.
